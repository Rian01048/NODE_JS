# Conexão Node.js com MySQL

Projeto simples para conectar o Node.js ao MySQL, criar uma tabela e inserir dados.

## Dependências

Você precisará instalar o `mysql2` (para comunicar com o banco) e o `dotenv` (para ler o arquivo com suas senhas). 

No terminal, rode os comandos:

```bash
npm i mysql
npm i mysql2 dotenv
npm init -y
